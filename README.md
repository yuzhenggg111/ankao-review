# 皖本复习台 0.2

真题驱动版，面向安徽 2027 专升本大学语文、英语的个人复习。

## 本版变化

- 主导航改为“今日、题型突破、真题库、训练场、错题、进度”。
- 建立2022—2026年五年、两科共10个科目年度的真题索引。
- 英语按词汇与结构、完形填空、阅读理解、句子翻译、短文写作拆分。
- 大学语文按语言基础与文学常识、名句默写、古诗鉴赏、文言文阅读、现代文阅读、文学写作拆分。
- 每个题型都有识别信号、执行步骤、易错陷阱和方法回执。
- 第一批可做真题：
  - 2024英语词汇与结构15题。
  - 2023英语词汇与结构15题。
  - 2024英语完形填空10题。
  - 2024英语阅读方法题2题。
  - 2024英语翻译方法题5题。
  - 2024语文语言基础与文学常识10题。
- 训练完成后自动生成错题、记录首次正确率，并显示题型方法回执。
- 学习进度只保存在当前浏览器 `localStorage` 中。

## 资料状态

2022—2026年两科试卷主体已经由购买资料覆盖，并有针对性地与公开来源交叉核验。

仍需注意：

- 英语2022—2026尚未完成全部答案核验。
- 大学语文2022—2024答案册存在部分空白、顺序错位。
- 2025—2026部分答案仍需要第二来源或人工复核。
- 购买资料为水印数字整理版，不标作官方原卷。

详细资料核验见：

`../research/安徽专升本公共课真题资料核验报告.md`

## 打开方式

直接打开 `index.html`。本版不依赖网络、账号或服务器。

## GitHub Pages 发布

1. 新建一个公开仓库，例如 `ankao-review-v2`。
2. 上传本目录内的全部文件，不能只上传 `index.html`。
3. 打开仓库的 **Settings → Pages**。
4. Source 选择 **Deploy from a branch**。
5. Branch 选择 **main**，目录选择 **/ (root)**。
6. 保存后等待1—3分钟。

访问地址通常为：

```text
https://<GitHub用户名>.github.io/ankao-review-v2/
```

如果直接更新现有仓库，则可以覆盖原文件并提交，原网址保持不变。
