# 皖本复习台 0.1

面向安徽 2027 专升本大学语文、英语的个人复习网页首版。

## 打开方式

直接双击 `index.html`，使用 Edge、Chrome 或平板/手机浏览器打开即可。页面不依赖网络和外部图片。

学习进度、诊断结果、答题记录和错题保存在当前浏览器的 `localStorage` 中。换浏览器、清除浏览器数据或更换设备后，记录不会自动同步。

## GitHub Pages 发布

这个目录已经可以直接作为 GitHub Pages 站点使用，资源路径都是相对路径，并包含 `.nojekyll`。

使用网页上传时：

1. 在 GitHub 新建一个公开仓库，例如 `ankao-review`。
2. 进入仓库，选择 **Add file → Upload files**。
3. 上传本目录中的全部文件，不要只上传 `index.html`。
4. 提交到 `main` 分支。
5. 打开 **Settings → Pages**，选择 **Deploy from a branch**。
6. 分支选择 `main`，目录选择 `/ (root)`，保存。
7. 等待部署完成，访问 `https://<用户名>.github.io/ankao-review/`。

如果仓库名使用 `<用户名>.github.io`，站点地址会直接是 `https://<用户名>.github.io/`。

GitHub Pages 的网页本身是公开访问的。本应用没有服务器、登录或资料上传功能，学习进度仍只保存在访问者自己的浏览器中。

## 本版包含

- 12 道零基础起点诊断，只用于安排学习顺序，不预测考试分数。
- 按 45 分钟、90 分钟或周末深度自动组合每日任务。
- 英语字母、10 个起步词、句子主干、be 动词和阅读定位示范课。
- 大学语文 15 篇背诵篇目总览、文言实词和现代文阅读方法。
- 四组原创基础练习及一组 8 分钟混合小测。
- 自动错题本、首次作答正确率、连续学习记录和阶段进度。
- 手机、平板和桌面响应式布局。
- “资料核验中心”，显示哪些内容已读取大纲、哪些仍是原创练习、哪些真题资料尚待核验。

## 可信度规则

本版不会把原创题或改编题冒充历年真题。

- “依据大纲”：内容来自本轮读取的 16 页考试说明。
- “原创练习”：为诊断和巩固基础编写，不用于推断命题频率。
- “待核验”：尚未取得可靠原卷或答案，不进入正式训练。
- “已核对”：只有完成来源和答案核对后才会使用。

当前正式考试通知、统一考试历年真题及可信答案尚未导入。考试日期暂按 2027 年 4 月 17 日估算，目的是展示倒计时，正式日期以官方公告为准。
